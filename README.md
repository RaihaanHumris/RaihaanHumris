## 👨‍💻 About Me

Halo! Saya **Muhammad Raihaan Humris**, seorang pengembang aplikasi web dan mobile yang berfokus pada pembuatan solusi digital yang fungsional, modern, dan *scalable*.

- 🎓 **Pendidikan:** Saat ini menempuh pendidikan di **MAKN Ende** dan sedang mempersiapkan diri untuk program **Praktik Kerja Lapangan (PKL)**.
- 🚀 **Fokus Pengembangan:** Terbiasa membangun aplikasi dari nol (*end-to-end*), meliputi **Sistem Manajemen Inventaris**, **Platform Pembelajaran Interaktif**, hingga **Katalog & Aplikasi Streaming**.
- 🎯 **Minat & Disiplin:** Di luar pemrograman, saya rutin berlatih *calisthenics workout* serta mendalami penalaran matematika untuk persiapan **SNBT & Ujian Mandiri**.
- 📫 **Kolaborasi:** Terbuka untuk diskusi proyek, peluang magang/PKL, dan kolaborasi *open-source* melalui [raihaanhumris@gmail.com](mailto:raihaanhumris@gmail.com).
